# அப்பா — A Royal Birthday Tribute

A luxury, editorial-grade birthday tribute website celebrating Appa (Dad), built with Tamil scrollytelling, dynamic live lifetime counter, background BGM, and interactive photo memories.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FNITHIN4747%2Fappa)

## ✨ Features
- **Cinematic Entrance Gate**: A solitary golden button (`▶ உள்ளே நுழையவும்`) with ambient halo pulse that begins the background music upon entry.
- **Sticky Scrollytelling Hero**: Interactive chapter progression across Dad's milestone years with live dynamic lifetime calculator.
- **Background BGM**: Jilla Appa Theme played on loop with a discreet floating audio toggle and animated equalizer bars.
- **Editorial Kavithai Gallery**: Clean Tamil typography with smooth hover previews and royal modal pop-ups for cherished photos.
- **Fully Responsive**: Optimized for desktop, tablets, and mobile screens.
